\begin{abstract}
Vision-language models (VLMs) often read text from images, including code-switched text such as a screenshot of a Hinglish tweet. It is unknown whether the attention heads that matter for a language when it arrives as text tokens also matter when it arrives as a rendered image. We study this question in four open VLMs with at most 3B parameters. We score every attention head with gradient-based head importance (LAHIS) on monolingual English, Spanish, and Hindi sentences. Each sentence is given as text, as a rendered image with a query, and as a rendered image alone. We also probe the vision encoders for script identity and ablate the top heads while the models read Hindi-English code-switched images. The answer depends on the model. Qwen2-VL-2B and SmolVLM use largely different heads for text and image input. InternVL3-2B uses nearly the same heads, but only for Hindi. For PaliGemma-3B, the overlap measure cannot separate either pattern from chance. All four vision encoders encode script identity from their first layer. Zero-ablating the top 20 heads for either language destroys generation in every model, while ablating 20 random heads does not. The top heads are therefore necessary for coherent output, but the ablation does not show that they route language. A script-change metric counts this collapse as a change of script, so head-ablation studies need a check on output quality. We release the pipeline, the corpus, and the per-head scores.
\end{abstract}

\section{Introduction}
\label{sec:intro}

VLMs read text from images such as screenshots, photographed notes, and scanned documents. This text is often code-switched, which means it alternates between two languages within one sentence. A VLM must then identify both languages from pixels, without the token boundaries that a text-only model receives.

A VLM passes an image through a vision encoder and sends the resulting tokens to a language decoder. The same decoder also reads text tokens directly. Mechanistic studies have located the attention heads and neurons that matter for language processing in text-only models \citep{liu2026lahis, tang2024neurons}. Studies of VLMs have located heads that read text in images, but only for English \citep{baek2025ocr}. It is unknown whether the decoder relies on the same heads for a language when it reads that language as text tokens and as image tokens.

The answer determines whether findings about language heads in text models transfer to visual input. If both input paths use the same heads, text-only findings apply to images. If they use different heads, the visual path needs its own analysis.

We compare the two paths with three input conditions. Each sentence is given as text (condition A), as a rendered image with a fixed query (condition B), and as a rendered image alone (condition C). Comparing A with C isolates the input modality. Comparing B with C isolates the effect of the query. We score every attention head in each condition with LAHIS \citep{liu2026lahis} and study four open VLMs from three decoder families. We ask two research questions and one exploratory question:

\begin{itemize}
    \item \textbf{RQ1.} When the same sentence reaches a VLM as text tokens and as a rendered image, does the model rely on the same attention heads?
    \item \textbf{RQ2.} When a VLM reads code-switched text from an image, does ablating the top heads change the language of its output more than ablating random heads?
    \item \textbf{Exploratory.} Do the positions of the top heads match across models that share a decoder family?
\end{itemize}

We first test a precondition. The vision encoder must represent script identity (Latin or Devanagari) for the image path to route language by script.

Following \citet{liu2026lahis}, we identify heads on monolingual sentences. Code-switched text enters the study in two places. The script probes read mixed-script images, and the ablation test in RQ2 removes the identified heads while the model reads code-switched images.

We find the following:
\begin{itemize}
    \item \textbf{Script identity is available early.} All four vision encoders separate Latin from Devanagari script from their first layer (Section~\ref{sec:probes}).
    \item \textbf{Head sharing depends on the model.} Two models use largely separate heads for text and image input, one shares them for Hindi only, and one is inconclusive. Where the sets differ, the text heads concentrate in the first two decoder layers and the image heads do not (Section~\ref{sec:overlap}).
    \item \textbf{The top heads are necessary but not shown to route language.} Zero-ablating them destroys generation in all four models, while random heads do not. The ablation cannot isolate a role in routing language (Section~\ref{sec:ablation}).
    \item \textbf{Shared positions across models match layer placement.} The two Qwen-family models share about as many head positions as their layer placement predicts (Section~\ref{sec:lineage}).
\end{itemize}

We study four small VLMs, two language pairs, and one attribution method. We report results per model and rate the evidence for each observation (Section~\ref{sec:conclusions_table}). We make no claim that the patterns hold for other VLMs.

\section{Related Work}
\label{sec:related}

\paragraph{Language heads and neurons in text LLMs.}
\citet{liu2026lahis} introduce LAHIS, which scores attention heads with one forward and one backward pass through a differentiable head mask. They find that a small set of heads matters most for language identification in multilingual LLMs. \citet{tang2024neurons} identify language-specific neurons by contrasting activations on parallel corpora. Deactivating these neurons degrades only the corresponding language. \citet{wendler2024llamas} show that intermediate representations of Llama-2 are closer to English than to the input or output language. All of this work studies text input only.

\paragraph{Language confusion and code-switching.}
\citet{nie2025confusion} trace language-confusion errors in English-centric LLMs to specific token positions and late-layer transitions. We know of no mechanistic study of code-switching itself, and of none that covers visual input.

\paragraph{Language heads in VLMs.}
\citet{ye2025claim} identify cross-lingual attention misalignment in VLMs and intervene on it to reduce multilingual object hallucination. They study monolingual queries in several languages and do not separate the text path from the image path. \citet{baek2025ocr} identify OCR heads that read text in images, but only for English text.

\paragraph{Reading text from pixels.}
Several models process rendered text directly as pixels \citep{rust2023pixel, tschannen2023clippo} or read documents and screenshots without an OCR step \citep{kim2022donut, lee2023pix2struct}. CLIP's image encoder matches images of words with images of the scenes they describe, and its spelling ability can be isolated in a separate subspace \citep{materzynska2022disentangling}. Many attention heads in CLIP's image encoder have property-specific roles, such as location or shape \citep{gandelsman2024interpreting}. Our script probes test a narrower property, script identity, in the vision encoders of VLMs.

\paragraph{Visual information in the decoder.}
Causal tracing has been adapted to VLMs to locate where image information is stored and transferred \citep{palit2023towards, basu2024understanding}. \citet{neo2025towards} track how visual token representations change across the layers of LLaVA's language model. None of these studies compares the heads used for the same content as text and as an image.

\paragraph{Gap.}
No prior work compares, head by head, which heads a VLM relies on for the same sentence as text and as a rendered image. Our design also separates the effect of the query from the effect of modality.

\section{Data}
\label{sec:data}

All code-switched text is real and human-produced, with gold token-level language labels. We do not use synthetic code-switching, because word substitution can produce sentences that bilingual speakers would not write.

The Hindi-English data are the Devanagari-script Twitter portion of the GLUECoS part-of-speech corpus \citep{khanuja2020gluecos}. The Spanish-English data are the code-switched sentences of the Bangor Miami corpus of transcribed speech \citep{deuchar2014building}. Monolingual English, Spanish, and Hindi sentences come from FLORES-200 \citep{nllb2022}.

\paragraph{Cleaning.}
We apply Penn Treebank detokenization and filters for script consistency and noise. A two-stage fluency filter first applies heuristic checks and then removes the quartile with the highest Qwen2.5-0.5B perplexity in each language pair. A content filter removes profanity and political material, judged by Claude against a fixed rubric. We record the reason for every removed sentence. The final corpus has 806 Hindi-English sentences from the GLUECoS training and development splits, 127 Spanish-English sentences, 750 monolingual sentences (250 per language), and 100 transliteration controls. The controls are Hindi sentences written in Latin script, so they separate script from language.

\paragraph{Data for each analysis.}
\begin{itemize}
    \item \textbf{Head importance (RQ1).} For each language, 100 of the 250 monolingual FLORES-200 sentences. Conditions B and C use rendered images of the same sentences. No code-switched text is used to identify heads.
    \item \textbf{Script probes.} The first 300 rendered code-switched images, 127 Spanish-English and 173 Hindi-English. All Devanagari patches therefore come from the Hindi-English images.
    \item \textbf{Hindi-English ablation (RQ2).} 100 sentences sampled from the 806 Hindi-English sentences. These are disjoint from the sentences used to identify heads.
    \item \textbf{Spanish-English ablation.} The first 100 of the 127 Spanish-English sentences.
\end{itemize}

\paragraph{Rendering.}
Each sentence is kept as raw text and rendered as black text on a white image. Each token is drawn in a font for its script, Noto Sans for Latin and Noto Sans Devanagari for Devanagari. We record a bounding box for every token, which gives each image patch a script label. Figure~\ref{fig:stimuli} shows examples.

\section{Models}
\label{sec:models}

We study four open VLMs that differ in vision encoder, decoder family, and image-token compression. Each has at most 3B parameters, which keeps gradient attribution over every head within our compute budget.

\begin{itemize}
    \item \textbf{Qwen2-VL-2B-Instruct} \citep{wang2024qwen2vl} pairs a custom 2D-RoPE vision transformer (0.67B) and a $2{\times}2$ patch merger with a Qwen2-1.5B decoder (28 layers, 12 heads per layer).
    \item \textbf{InternVL3-2B} \citep{zhu2025internvl3} pairs InternViT-300M-448px-V2.5 and pixel-shuffle compression with a Qwen2.5-1.5B decoder (28 layers, 12 heads per layer).
    \item \textbf{SmolVLM-Instruct} \citep{marafioti2025smolvlm} pairs a SigLIP-SO400M encoder \citep{zhai2023sigmoid} and a pixel-shuffle connector with a SmolLM2-1.7B decoder (24 layers, 32 heads per layer).
    \item \textbf{PaliGemma-3B (mix-448)} \citep{beyer2024paligemma} pairs a SigLIP-SO400M encoder at 448 pixels and a linear projector with a Gemma-2B decoder (18 layers, 8 heads per layer, multi-query attention). The projector keeps all 1,024 image tokens. PaliGemma-3B is a prefix language model, so we score its decoder on the text after the prefix \texttt{[BOS]\,\textbackslash n}.
\end{itemize}

Qwen2-VL-2B and InternVL3-2B use decoders from the same family. Qwen2.5 was pretrained on 18 trillion tokens, against 7 trillion for Qwen2 \citep{qwen2024qwen25}. The Qwen2.5 report does not state whether Qwen2.5 was initialized from Qwen2 weights. SmolVLM uses a Llama-architecture SmolLM2 decoder, and PaliGemma-3B uses a Gemma decoder. Both come from separate pretraining lineages.

\paragraph{Language competence.}
We check that each extracted decoder models each language before we score heads, so that the scores do not reflect noise. Table~\ref{tab:competence} reports decoder perplexity on monolingual FLORES-200 text. Per-token perplexity cannot be compared across languages. Tokenizer fertility differs by 3.4 to 3.6 times between English and Devanagari Hindi, which lowers Hindi's per-token perplexity regardless of competence. We therefore normalize by characters, $\mathrm{ppl}_c = \exp(\mathrm{NLL}/n_{\mathrm{chars}})$, and use this value for all cross-language comparisons. All models stay below a per-token threshold of 100 except PaliGemma-3B on Spanish (114.7). We keep PaliGemma-3B because its character-normalized Spanish perplexity lies within the range of the other models.

\subsection{Input conditions}
\label{sec:conditions}

Each sentence is scored in three conditions:
\begin{description}
    \item[A (text)] The decoder reads the raw sentence. The vision encoder does not run.
    \item[B (image+query)] The full VLM reads the rendered sentence with the fixed query ``Read this:''. The loss is computed on the sentence as the target.
    \item[C (image-only)] As in B, but the query is empty. The chat template and role tokens are identical to B.
\end{description}

Comparing B with C isolates the effect of the query. Comparing A with C isolates the effect of modality. Condition A uses the decoder taken from inside the VLM after vision-language training, not the original pretrained checkpoint. This keeps the comparison between A and C free of differences caused by vision-language training.

\subsection{Head importance}
\label{sec:lahis}

Following \citet{liu2026lahis}, we multiply the output of each head $h$ in layer $\ell$ by a mask value $M_{\ell,h}$, initialized to one. We apply the mask at the input of each layer's attention output projection, where the head outputs are still separate. The importance of a head is $|\partial \mathcal{L} / \partial M_{\ell,h}|$, where $\mathcal{L}$ is the language-modeling loss over all tokens of a sentence. We average this score over 100 sentences per language and condition. Appendix~\ref{app:lahis} shows the resulting layer-by-head maps.

\paragraph{What the score measures.}
The LAHIS loss is the standard next-token loss and does not target language identity. A head scores high if masking it hurts prediction of text in the given language. This includes heads with general functions, such as tracking position or copying earlier tokens. A high score therefore marks a head as important for processing a language, including language-general heads. Section~\ref{sec:lineage} shows that most top heads are shared across the three languages.

\subsection{Head overlap}
\label{sec:overlap_method}

For each model, language, and condition, we take the 20 highest-scoring heads and compute the Jaccard overlap between conditions. The chance level is the 95th percentile of the overlap between random 20-head sets, over 10{,}000 draws from each model's grid. We repeat the analysis for $K \in \{5, 10, 20, 40, 80\}$ heads. For the cross-model analysis, we count the (layer, head) positions that two models' text-condition sets share.

\subsection{Script probes}
\label{sec:probe_method}

At every vision-encoder layer, we train a linear probe to predict whether an image patch shows Latin or Devanagari script. Patch labels come from the token bounding boxes, mapped onto the grid of image tokens that the decoder receives. This grid differs from the raw patch grid when a patch merger or pixel shuffle compresses the tokens. We exclude background patches, so chance accuracy is 0.5. We sample 100 patches per image and 4,000 text patches per layer. The probe is a class-balanced logistic regression, evaluated by balanced accuracy with stratified 5-fold cross-validation. The folds split patches, not images (Section~\ref{sec:limitations}).

\subsection{Ablation}
\label{sec:ablation_method}

Gradient scores are correlational, so we test whether the top heads affect generation. We set the output of a head set to zero and generate from 100 Hindi-English code-switched images, with greedy decoding and a limit of 64 tokens. The ablated sets are the 20 highest-scoring text-condition heads for English and for Hindi. We call them English heads and Hindi heads after the language used to score them. The sets are not contrasted between languages, and they overlap heavily (Section~\ref{sec:lineage}).

We use two controls. The random-head control ablates 20 heads drawn from outside both top-20 sets. Mean ablation replaces each head's output with its mean over token positions in the same image's un-ablated forward pass. We run the ablation once and then three more times with new seeds. Each seeded run draws its own 100 sentences and its own random heads.

We measure two outcomes. The first is the script label of each output, which is Latin, Devanagari, other, or none for output without letters. A script change is any change of label from the un-ablated output. The second is fluency. An ablated output counts as fluent if it keeps at least half of the words of the un-ablated output for the same image. This proxy is coarse, so we compare it against the random-head control. Spanish-English uses one script, so for it we run a language identifier (\texttt{langid}) on the output instead.

\section{Results}
\label{sec:results}

\subsection{Script identity is decodable from the first layer of every vision encoder}
\label{sec:probes}

All four vision encoders separate Latin from Devanagari patches above chance from layer 0 (Figure~\ref{fig:probes}, Table~\ref{tab:probes}). Accuracy varies widely across encoders. InternVL3-2B and PaliGemma-3B reach near-perfect accuracy, Qwen2-VL-2B plateaus near 0.81, and SmolVLM stays near 0.63 at every depth.

The same encoder family can give very different results. PaliGemma-3B and SmolVLM both use SigLIP-SO400M, but they sit at opposite ends. PaliGemma-3B runs the encoder at 448 pixels and keeps all 1,024 patch tokens, while SmolVLM gives it lower-resolution, pooled tokens. All models see the same images and fonts, so this deployment difference is a likely cause.

The probes track script rather than language. Each model's best-layer probe labels most transliteration controls as Latin, at rates at or above its accuracy on code-switched images (Table~\ref{tab:probes}). These controls are new images, so the patch-level cross-validation does not affect this check. Script identity is therefore available to every decoder. Differences between text and image head sets (Section~\ref{sec:overlap}) do not come from a missing script signal.

\subsection{Whether text and image inputs share heads depends on the model (RQ1)}
\label{sec:overlap}

Figure~\ref{fig:overlap} compares two overlaps for each model and language. The first is between the text and image-only head sets ($\AcapC$). The second is between the two image conditions ($\BcapC$). Table~\ref{tab:overlap} in Appendix~\ref{app:overlap} lists all values. The four models show three patterns.

\begin{figure}[t]
\centering
\includegraphics[width=\linewidth]{figures/overlap_dumbbell.pdf}
\caption{Text and image inputs use separate heads in Qwen2-VL-2B and SmolVLM, nearly the same heads in InternVL3-2B for Hindi, and an unresolved pattern in PaliGemma-3B. Circles show text versus image-only overlap ($\AcapC$). Squares show image+query versus image-only overlap ($\BcapC$). Shading marks each model's chance level.}
\label{fig:overlap}
\end{figure}

\paragraph{Separate heads in Qwen2-VL-2B and SmolVLM.}
In both models, text-image overlap stays low for every language, while the two image conditions overlap strongly. Once an image is present, these models use a consistent head set, with or without a query. That set differs from the head set for the same sentence as text.

\paragraph{Shared heads for Hindi in InternVL3-2B.}
InternVL3-2B uses nearly the same heads for Hindi as text and as an image. Its Hindi text-image overlap is 0.667, well above its English and Spanish overlaps. Hindi competence does not explain this result. Qwen2-VL-2B models Hindi at least as well (Table~\ref{tab:competence}) and keeps its heads separate. With one model and one language, we treat this result as tentative.

\paragraph{Inconclusive overlap in PaliGemma-3B.}
All of PaliGemma-3B's overlaps lie between 0.21 and 0.33, modestly above its chance level of 0.143. Its image-image overlap is not higher than its text-image overlap. Its grid has only 144 heads, so a top-20 set covers a large fraction of it and Jaccard overlap loses resolution.

\paragraph{Layer placement.}
The layer placement of the top heads matches these patterns (Figure~\ref{fig:layers}, Table~\ref{tab:layers}). Qwen2-VL-2B places almost all of its text-condition heads in layers 0--1 but few of its image-condition heads there. InternVL3-2B also places its text-condition heads early. For Hindi, its image-condition heads are early as well, which matches its shared Hindi heads. SmolVLM places its text-condition heads partly early and its image-condition heads mostly later. PaliGemma-3B places few heads in layers 0--1 in any condition.

\paragraph{Robustness.}
The three patterns hold for every $K$ from 5 to 80 (Appendix~\ref{app:ksweep}).

\paragraph{Encoder signal and shared heads.}
A strong script signal in the encoder does not by itself lead to shared heads. InternVL3-2B and PaliGemma-3B have the strongest script signals, but only InternVL3-2B shares heads. PaliGemma-3B's overlap is inconclusive, so this comparison is weak.

\subsection{The top heads are necessary for coherent output, but ablation does not isolate language routing (RQ2)}
\label{sec:ablation}

Zero-ablating the top 20 heads for either language destroys generation in every model (Figure~\ref{fig:fluency}). At most 1\% of outputs stay fluent, against 71--76\% for the random-head control. The collapse takes a different form in each model. PaliGemma-3B mostly returns empty strings. Qwen2-VL-2B returns output without letters or with fragments of Chinese, Japanese, or Korean (CJK) characters. InternVL3-2B's Hindi-head ablations contain CJK characters in every output, and SmolVLM repeats a special token. No un-ablated output contains CJK characters. Mean ablation also destroys generation, except for SmolVLM's Hindi heads. Appendix~\ref{app:ablation} gives the counts.

\centering

Mean ablation also destroys generation, except for SmolVLM's Hindi heads. Bars show the percentage of 400 generations that keep at least half of the un-ablated output's words.}
\label{fig:fluency}

The top heads are therefore necessary for coherent output, and a random set of the same size is not. The ablation does not show that these heads route language. English heads and Hindi heads cause the same collapse, and the two sets largely coincide (Section~\ref{sec:lineage}). In Qwen2-VL-2B they cover almost all 24 heads in layers 0--1, so the collapse may reflect general damage to the first layers. A test of language routing needs a random control drawn from the same layers and head sets contrasted between languages.

A script-change rate misreads this collapse as a change of language. Output without letters changes the script label and therefore counts as a script change. In the single run, all 74 script changes after ablating Qwen2-VL-2B's Hindi heads were outputs that lost all letters, and so were all 97 for PaliGemma-3B. InternVL3-2B shows a low rate because its collapsed outputs keep enough Latin letters to retain a Latin label. Differences in script-change rate between models therefore reflect how each model fails, not how it routes language. Appendix~\ref{app:ablation} reports the script-change rates. The Spanish-English rates, based on a language identifier, have not been checked for collapse.

Without ablation, SmolVLM produces Devanagari output for 37 of 100 images, against 5 to 15 for the other models. Competence does not explain this, because SmolVLM has the highest Hindi perplexity (Table~\ref{tab:competence}). We leave its cause open.

\subsection{Shared head positions across models match layer placement (exploratory)}
\label{sec:lineage}

Most top text-condition heads are shared across languages within each model. The number of heads in the top 20 for all three languages is 18 for Qwen2-VL-2B, 14 for InternVL3-2B, 14 for SmolVLM, and 15 for PaliGemma-3B. LAHIS therefore mostly ranks language-general heads. The English and Hindi sets ablated in Section~\ref{sec:ablation} are largely the same heads.

Across models, the two Qwen-family models share the most head positions (Table~\ref{tab:crossmodel}). The other pairs share far fewer, and SmolVLM and PaliGemma-3B share none.

Layer placement predicts the overlap of the Qwen-family pair. Both models place most of their top text-condition heads in layers 0--1, which hold 24 heads in each model. If each model placed those heads at random within the two layers, the sets would share about 11, 15, and 15 positions for English, Spanish, and Hindi. The observed counts are 13, 16, and 15. The other models place fewer top heads in layers 0--1 and have differently shaped grids, so they share fewer positions.

A shared head position has no meaning beyond layer placement unless the two models share initialization. Heads within a layer are interchangeable across independently trained models. The Qwen2.5 report does not state whether Qwen2.5 was initialized from Qwen2 weights (Section~\ref{sec:models}), and the other pairs come from separate lineages. The data therefore show a layer-level pattern. With four models, decoder family varies together with head count, grid shape, attention type, and image compression. Our data cannot show whether the pattern follows decoder family.

Two points follow for interpretability research on VLMs. First, language heads found in one VLM may not transfer to another. Our four models differ in whether text and image inputs share heads, in where their top heads sit, and in how well their encoders separate scripts. Second, head-ablation studies should check output quality. In our study, a script-change metric recorded collapsed output as a change of script and produced differences between models that disappear under a fluency check.

\section{Limitations}
\label{sec:limitations}

\paragraph{Model scale.}
All four models have at most 3B parameters. Larger VLMs may organize text and image processing differently.

\paragraph{Monolingual head identification.}
We identify heads on monolingual sentences. RQ1 therefore compares text and image processing of single-language content, and code-switched text enters only through the probes and the ablation. Scoring heads on code-switched sentences, with the loss restricted to one language's tokens, would link the head sets directly to code-switched input.

\paragraph{Ablation design.}
The ablations use absolute top-20 sets, a random control drawn from the whole network, and a coarse fluency proxy. These choices can show that the heads are necessary for coherent output. They cannot show what role the heads play in routing language.

\paragraph{Probe evaluation.}
The probe folds split patches, not images, so patches from one image can appear in both training and test data. This likely inflates the reported accuracy. The transliteration check uses new images and is not affected. All Devanagari patches also come from the 173 Hindi-English images among the 300 probed.

\paragraph{Single-run overlap.}
The overlap values come from one run, with the permutation baseline as the only control. Their variance across runs is unknown.

\paragraph{Covarying architecture.}
Decoder family varies together with grid shape, head count, attention type, and image compression. We cannot attribute a difference between models to any one of these factors.

\paragraph{Two language pairs.}
With two language pairs, we cannot tell whether InternVL3-2B's Hindi-specific overlap depends on script or on language family.

% ============================================================
\section{Conclusion}
\label{sec:conclusion}

We compared the attention heads that four small VLMs rely on when a sentence arrives as text and as a rendered image. The answer depends on the model. Two models use largely separate heads, with the text heads concentrated in the first decoder layers. One model uses nearly the same heads for Hindi only, and for one model our measure is inconclusive. All vision encoders encode script identity from their first layer, so these differences do not come from a missing script signal. Ablating the top heads destroys generation in every model, while ablating random heads does not. The top heads are therefore necessary for coherent output, but the ablation cannot show that they route language. A script-change metric counts this collapse as a change of script, so head-ablation studies need a check on output quality. Future work can score heads on code-switched text, contrast heads between languages, use controls matched by layer, and test larger VLMs and language pairs that separate script from language family.
